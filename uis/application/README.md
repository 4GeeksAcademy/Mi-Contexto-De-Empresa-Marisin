# TrackFlow Backoffice

Aplicacion interna de TrackFlow construida con Next.js App Router, TypeScript y Tailwind CSS.

## Integraciones

- Reutiliza la logica operativa de [src/utils](../../src/utils) y [src/types](../../src/types)
- Reutiliza el servicio de talento existente en [uis/talent-pipeline-tracker/services/api.ts](../talent-pipeline-tracker/services/api.ts)

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run start
```
