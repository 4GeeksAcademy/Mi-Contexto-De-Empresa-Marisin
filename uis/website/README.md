# TrackFlow Website

Aplicacion web publica de TrackFlow construida con Next.js (App Router), TypeScript y Tailwind CSS.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

- Landing corporativa en `/`
- Formulario B2B con validaciones estrictas
- Marcado SEO con Schema.org (`Organization`)
